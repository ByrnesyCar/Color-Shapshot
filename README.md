# Color Snapshot

Hosted seasonal color-analysis prototype for testing local, browser-based facial-region measurements and the Color Snapshot scoring framework.

## Current test stage
5E-1: photo quality, facial landmark detection, and provisional Value / Contrast / Chroma / Temperature observations.

This is a calibration prototype, not a final color diagnosis. The -3 to +3 mappings are provisional and must be tested across varied controlled photographs before guest use.
